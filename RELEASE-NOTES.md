# Sonic Frameworks Quick UI Release Notes

Sonic Frameworks Quick UI is the toolkit behind modern, adaptable SonicDE apps that look great on any screen size.

## Unreleased

- App toolbars at the top of a window can now blend with the title bar, see-through and blurred when the theme asks for it, updating as soon as the setting changes. Themes that don't use this look the same as before.
- Behind the scenes: new toolkit pieces for app developers (`Theme.toolsArea`, `ToolsAreaBackground`, `ToolsAreaRegion`, `ToolsAreaWindowBackground`), with automatic tests.

## 6.31.0 (2026-10-20)

- Settings forms no longer force a minimum width and line up neatly without stray gaps, so they fit narrow windows better.
- Behind the scenes: version number updated for this release.

## 6.30.0 (2026-09-12)

- Fixed sizing problems in settings forms, including labels that appeared when they had nothing to show.
- Behind the scenes: added automatic tests for form sizing, the bundled example no longer needs older compatibility libraries, and the version number was updated for this release.

## 6.29.0.2 (2026-08-21)

- Side drawers now size themselves correctly inside ordinary windows, not just main app windows.

## 6.29.0.1 (2026-08-20)

- Behind the scenes: tests now use the Silver default wallpaper.

## 6.29.0 (2026-08-07)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.28.0.1 (2026-08-04)

- Behind the scenes: better support for code editors and restored the project's code formatting rules.
